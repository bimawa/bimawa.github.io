# Audit: July 2026 — bimawa.net

## ✅ Fixed

- `.env` comment: "Hugo blog" → "Zola blog"

## 🔴 Blockers (build errors or broken rendering)

1. **RU front page shows EN content** — `templates/index.html` calls `get_section()` without `lang` param. Always fetches English section even on RU locale. Fix: add `lang=lang` to all `get_section()` calls in `index.html`.

2. **Tags pages crash** — `templates/tags/single.html` and `templates/tags/list.html` use `title_macros::title()` and `post_macros::list_posts()` without importing those macros. Fix: add `{% import "macros/title.html" as title_macros %}` etc. or remove calls.

## 🟡 Issues (incorrect but non-breaking)

3. **Language switcher double slashes** — `templates/base.html` produces `//about/` instead of `/about/` when switching from RU. Fix: simplify the `replace` chain.

4. **Zola version mismatch** — CI uses `shalzz/zola-deploy-action@v0.21.0` (bundles Zola 0.21.0) but local is 0.22.0. Should either pin local to 0.21.0 or upgrade action.

5. **TradeTerminal missing from JS** — `static/menu-projects.js` lists all projects except TradeTerminal.

6. **WireDeskVR date mismatch** — `content/projects/WireDeskVR/2025-11-15_wireDeskVR.md` has `date = 2023-05-15` in front matter. Filename says 2025.

7. **`just project` creates incomplete _index** — New project `_index.md` lacks `template` field. Should default to `template = "index<Name>.html"` or at least a fallback.

8. **"Nerworking" typo** — `content/projects/2025-12-10_netmonRS.md`, `content/projects/2025-12-10_netmonRS.ru.md`, and `content/projects/Netmonrs/2025-12-10T18:26:24Z_Network_monitor.md` all have `"Nerworking"` instead of `"Networking"`.

9. **Restore-blobs blog has template override** — `content/blog/2025-12-10T19:54:34Z_restore-blobs-from-git.md` sets `template = "index.html"` which is incorrect for a blog post.

10. **New post has stale placeholder** — `content/blog/2026-07-10T09:09:34Z_my-project-announce.md` description is `" [EN: translate]"` — test artifact not cleaned up.

## ⚪️ Minor / Cosmetic

11. **archive.md path override** — EN has `path = "archive"` explicit but RU doesn't.

12. **Project slugs mismatch** — Listing slugs differ from article slugs (tradeterminal vs trade_terminal, rfidreader vs rfid_reader). Works but inconsistent.

13. **Netmonrs directory name** — `content/projects/Netmonrs/` uses lowercase 'n' but title/template use 'NetMonRS'. Should be `NetMonRS/` for consistency.

14. **Feed config partial** — Only `[languages.ru]` has `generate_feeds = true`. EN has no feed generation.

15. **Root section paginate_by** — `content/_index.md` has `paginate_by=5` but template doesn't use pagination on root page.

## Recommendations

- **Fix blockers first**: RU front page (item 1), tags (item 2)
- **Then issues**: language switcher (3), CI version (4), JS menu (5)
- **Establish conventions as documented in** `.kiro/steering/blog-posts.md`
- **Consider a `just audit` command** that checks for common issues (missing RU/EN pairs, date mismatches, tag typos)
