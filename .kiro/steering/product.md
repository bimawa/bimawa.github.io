# Product: bimawa.net (bimawa.github.io)

**Purpose**: Personal portfolio + bilingual tech blog Maxim Bunkov (Bimawa).  
**Domain**: `bimawa.net`  
**Source**: `github.com/bimawa/bimawa.github.io`

## Core Content Types

| Type | Path | Purpose |
|---|---|---|
| Blog posts | `content/blog/` | Tech articles, project announcements, notes |
| Project cards | `content/projects/` | Short summary cards linking to detail pages |
| Project details | `content/projects/Name/` | Full project articles, changelogs, news |
| Static pages | `content/` root | About, CV, Contacts, Offer, Privacy, Terms, Archive |

## Principles

- **Bilingual first**: Every page exists in RU and EN. Create RU first, translate to EN.
- **Russian-first workflow**: Write in native language, then localise.
- **Quick documentation**: News per project updates with `just project-post` — no friction.
- **Zola SSG**: Rust-based static generator, output to `public/`, deployed via GitHub Pages.

## Audience

- Russian-speaking tech audience primarily
- International audience via English translations
- Potential clients / employers reviewing portfolio
